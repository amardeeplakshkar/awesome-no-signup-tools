# awesome-no-signup-tools
> Tools you can use instantly — no account, no sign-up. Curated, simple, and free to use — one line per entry.
- [Photopea](https://www.photopea.com/) — Edit PSD files in the browser, no account
- [Excalidraw](https://excalidraw.com/) — Hand-drawn style diagrams, starts instantly
- [tldraw](https://www.tldraw.com/) — A tiny whiteboard you can just open and draw on
- [Squoosh](https://squoosh.app/) — Compress images locally in your browser
- [TinyPNG](https://tinypng.com/) — Shrink PNG and JPG files in one drop
- [PDF24 Tools](https://tools.pdf24.org/) — Merge, split and convert PDFs for free
- [temp-mail.org](https://temp-mail.org/) — A disposable inbox in one click
- [wordcounter.net](https://wordcounter.net/) — Count words and characters as you type
- [time.is](https://time.is/) — Exact time, anywhere, no fuss
